# Парсер вакансий с hh.ru

Проект для парсинга вакансий с сайта hh.ru, создания базы данных PostgreSQL и анализа полученных данных.

## Описание проекта

Программа собирает данные о компаниях и их вакансиях с помощью публичного API hh.ru, сохраняет их в базу данных PostgreSQL и предоставляет удобный интерфейс для анализа. В проекте реализованы:

- Получение данных о 10 крупнейших IT-компаниях России
- Создание базы данных и таблиц для хранения информации
- Сохранение данных о компаниях и вакансиях
- Анализ данных через SQL-запросы:
  - Список компаний и количество их вакансий
  - Все вакансии с указанием зарплаты и ссылок
  - Средняя зарплата по всем вакансиям
  - Вакансии с зарплатой выше средней
  - Поиск вакансий по ключевым словам

## Запуск программы

### python main.py

## Использование

1. При запуске программа автоматически:
2. Создает базу данных hh (если она не существует)
3. Создает таблицы companies и vacancies 
4. Получает данные о компаниях через API hh.ru 
5. Получает вакансии для каждой компании 
6. Сохраняет данные в базу данных 
7. Выводит результаты анализа в консоль
